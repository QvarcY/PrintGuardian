# PrintGuardian v0.3.0-preview.1

**Public preview / Publiskais priekšskatījums — Windows x64**

PrintGuardian is now ready for its first public testing round. This is a usable preview, not a finished v1.0 product. The goal of this release is to put the real application in front of Bambu Studio / OrcaSlicer users, collect compatibility cases and improve the checks from real-world 3MF projects.

## LV — pirms palaišanas

### Windows var parādīt SmartScreen brīdinājumu

`v0.3.0-preview.1` tiek izplatīts **bez Authenticode digitālā paraksta**. Tāpēc Windows var parādīt zilu vai sarkanu **Microsoft Defender SmartScreen** logu ar tekstu “Windows aizsargāja jūsu datoru” / “Windows protected your PC” un nezināmu izdevēju.

Tas **pats par sevi nenozīmē, ka Windows ir atradis vīrusu vai ļaunprogrammatūru**. SmartScreen izmanto reputācijas signālus: lejupielādes vēsturi, konkrētā faila reputāciju un digitālā izdevēja parakstu. Ja programma nav parakstīta, Windows nevar sasaistīt jaunu PrintGuardian būvējumu ar uzticamu izdevēja identitāti, un katrai jaunai binārajai versijai reputācija lielā mērā sākas no jauna.

Šajā preview posmā mēs apzināti neizmantojam maksas komerciālu code-signing pakalpojumu. Parakstīšanu nākotnē pārskatīsim, ja būs piemērots bezmaksas/izmaksu ziņā pamatots risinājums vai projekta apjoms to attaisnos. Konkrēts termiņš netiek solīts, tāpēc arī nākamajos unsigned preview laidienos SmartScreen brīdinājums var atkārtoties.

**Turpini tikai tad, ja PrintGuardian lejupielādēji no oficiālās `QvarcY/PrintGuardian` GitHub Releases lapas.** Ja Windows piedāvā izvēli, atver **Papildinformācija / More info** un pēc avota pārbaudes izvēlies **Palaist tik un tā / Run anyway**. Dažās Windows konfigurācijās (piemēram, ar stingru Smart App Control vai organizācijas politiku) apiešana var nebūt atļauta.

ZIP ir pievienots `CHECKSUMS.txt`, ar kuru vari pārbaudīt lejupielādēto EXE SHA-256 kontrolsummas.

## Kas jauns

- Reāla Windows Portable un Installed versija.
- Portable dati paliek slēptajā `PrintGuardianData` mapē blakus EXE un pārvietojas kopā ar programmas mapi.
- Pēdējo projektu var turpināt pēc restartēšanas.
- Lokāla projektu vēsture ar līdz 20 pārbaudes kopsavilkumiem.
- Update Centre ar Preview/Stable kanāliem un GitHub Releases pārbaudi.
- Drukas profilu bibliotēka, Project Workspace, Guided Review un Profile Diff.
- Atbalstītām izmaiņām — pārbaudīts jauna 3MF eksporta ceļš, kas nepārraksta avota failu.
- Desktop versijā verificētais 3MF eksports tagad izmanto native Windows **Save As** logu; veiksmīga saglabāšana tiek paziņota tikai pēc faila faktiskas ierakstīšanas izvēlētajā vietā.
- Manuāli maināmām slicer vērtībām tiek saglabāts sākotnējais raw formāts, piemēram, `10% → 11%`; semantiski nemainīta vērtība vairs netiek uzskatīta par sagatavotu izmaiņu.
- Maintainer smoke testā gan Portable, gan Installed versijā izveidotais 3MF tika veiksmīgi atvērts Bambu Studio ar `Wall loops 1 → 2` un `Sparse infill density 10% → 11%`.
- Jauna redzama **Ziņot / ieteikt** poga blakus Buy Me a Coffee, lai testa lietotāji var ātri nosūtīt kļūdu vai ideju uz GitHub Issues.
- Windows ZIP sākas ar pašpietiekamu divvalodu **START HERE - SĀC ŠEIT.html** ceļvedi, kas vizuāli izskaidro SmartScreen, Portable/Installed izvēli, failu pārbaudi, lokālos datus un atjaunināšanu.

## Svarīgi ierobežojumi

- PrintGuardian **vēl neveic pilnu geometry/G-code drošības auditu**.
- “Nekas aizdomīgs netika atrasts” nozīmē tikai to, ka pašreiz atbalstītajās pārbaudēs netika atrasta problēma — tas nav drukas izdošanās vai drošības sertifikāts.
- 3MF saderība ar dažādiem Bambu Studio / OrcaSlicer projektiem tiek paplašināta tieši šajā publiskajā testēšanas posmā.
- Automātiska unsigned Installed atjauninājumu instalēšana ir apzināti izslēgta. Update Centre paziņo par laidienu un ved uz GitHub, bet instalēšana/Portable EXE nomaiņa ir manuāla.

## Kā ziņot

Aplikācijas augšējā joslā izmanto **Ziņot / ieteikt**. Vari izvēlēties:

- **Ziņot par problēmu** — kļūda, nepareizi nolasīts 3MF, crash, UI problēma u.c.;
- **Ieteikt uzlabojumu** — funkcija, UX ideja vai reāls darba scenārijs.

PrintGuardian pats ziņojumam nepievieno 3MF, profilu vai projekta saturu. Drošības ievainojamības, kurām nevajadzētu būt publiskām, sūti uz `info@craftin.lv`.

## EN — before you run it

### Windows may show a SmartScreen warning

`v0.3.0-preview.1` is distributed **without an Authenticode code-signing certificate**. Windows may therefore show a Microsoft Defender SmartScreen “Windows protected your PC” / unknown publisher warning.

This warning **does not by itself mean that Windows detected malware**. SmartScreen uses reputation signals such as download history, the reputation of the exact file, and a trusted publisher signature. Because this preview is unsigned, Windows cannot carry publisher reputation from one PrintGuardian build to the next in the same way a consistently signed application can.

At this preview stage the project is intentionally not purchasing a commercial signing service. Signing may be revisited if a suitable free/cost-effective option becomes available or the project reaches a stage where the cost is justified. No date is promised, so SmartScreen may appear again on later unsigned preview builds.

**Only continue if you downloaded PrintGuardian from the official `QvarcY/PrintGuardian` GitHub Releases page.** Where Windows allows it, choose **More info → Run anyway** after verifying the source. Some Windows security configurations can block unsigned applications without offering a bypass.

The Windows ZIP includes `CHECKSUMS.txt` with SHA-256 hashes for the EXE files.

## What's new

- Verified 3MF export on Windows now uses a native **Save As** dialog in both Portable and Installed builds, and reports success only after the file has actually been written.
- Supported manual slicer edits preserve source raw formatting, including percentage values such as `10% → 11%`; semantic no-op edits are no longer shown as prepared changes.
- Maintainer smoke testing confirmed exported copies reopen correctly in Bambu Studio with `Wall loops 1 → 2` and `Sparse infill density 10% → 11%`.
- The source 3MF remains untouched; PrintGuardian always creates a separate adjusted copy.

## Important limitations

PrintGuardian does not yet provide a complete geometry/G-code safety audit. A clean result only means that no problem was found by the checks implemented in this preview. Real-world Bambu Studio and OrcaSlicer compatibility is part of the public preview testing phase.

Use **Report / suggest** in the top bar to report a problem or propose an improvement. PrintGuardian does not automatically attach your 3MF, profiles, or project contents to the report. Security-sensitive findings should be sent privately to `info@craftin.lv`.
