PRINTGUARDIAN — WINDOWS
======================

Choose one option / Izvēlies vienu variantu:

1) PrintGuardian Portable.exe
   LV: Palaid programmu bez instalēšanas.
   EN: Run PrintGuardian without installing it.

2) Install PrintGuardian.exe
   LV: Instalē PrintGuardian Windows datorā un izmanto instalētās versijas atjaunināšanas plūsmu.
   EN: Install PrintGuardian on Windows and use the installed-edition update flow.

You do NOT need to open or edit application system files.
Aplikācijas sistēmas failus nav nepieciešams atvērt vai labot.

Project files are processed locally by the application workflow unless a future feature explicitly says otherwise.

HOW TO CONFIRM WHICH ONE YOU OPENED / KĀ PĀRBAUDĪT, KURU ATVĒRI
----------------------------------------------------------------
LV: Programmas augšējā joslā desktop versija rāda “Portable” vai “Instalētā”.
EN: The desktop app shows “Portable” or “Installed” in the top bar.

LV: Portable versija glabā savus profilus, iestatījumus un WebView datus slēptā PrintGuardianData mapē blakus EXE. Ja vēlies pārvietot Portable versiju kopā ar tās datiem, kopē visu izpakoto PrintGuardian mapi, ne tikai EXE.
EN: The Portable edition keeps its profiles, settings and WebView data in a hidden PrintGuardianData folder beside the EXE. To move Portable together with its data, copy the whole extracted PrintGuardian folder, not only the EXE.


UNINSTALL / ATINSTALĒŠANA
------------------------
LV: Instalēto versiju vari noņemt Windows Iestatījumi > Programmas > Instalētās programmas > PrintGuardian > Atinstalēt.
    Ērtībai izvēlnē Sākt tiek pievienota arī saīsne “Uninstall PrintGuardian”.
    Atinstalētājs piedāvā atsevišķi izvēlēties, vai dzēst arī PrintGuardian lietotnes datus un iestatījumus.
EN: Remove the installed edition from Windows Settings > Apps > Installed apps > PrintGuardian > Uninstall.
    A “Uninstall PrintGuardian” Start Menu shortcut is also created for convenience.
    The uninstaller separately lets you choose whether PrintGuardian application data and settings should also be deleted.

WINDOWS SECURITY / WINDOWS DROŠĪBA
----------------------------------
Development builds may currently show a Microsoft Defender SmartScreen unknown-publisher warning because they are not code-signed yet. Public preview release readiness requires trusted code signing; do not treat an unsigned development build as the final public package.
