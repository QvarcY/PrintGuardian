Ko nozīmē SmartScreen?
What does SmartScreen mean?
Nezināms izdevējs ≠ atrasts vīrussUnknown publisher ≠ virus detected
Vienkāršā valodā: ja pakotni lejupielādēji no PrintGuardian oficiālās GitHub Releases lapas, SmartScreen brīdinājums šajā preview versijā ir sagaidāms. Tas rodas tāpēc, ka izdevējs vēl nav digitāli parakstīts, nevis tāpēc, ka SmartScreen būtu paziņojis “PrintGuardian ir vīruss”. Windows Defender vai cita antivīrusa reāls ļaunprogrammatūras atradums būtu cita veida brīdinājums, un tādu nevajadzētu ignorēt.
In plain language: if you downloaded the package from the official PrintGuardian GitHub Releases page, a SmartScreen warning is expected for this preview. It appears because the publisher is not yet digitally signed, not because SmartScreen has declared “PrintGuardian is a virus”. An actual malware detection from Windows Defender or another antivirus is a different warning and should not be ignored.

Papildu faila pārbaude — tikai, ja vēliesAdvanced file verification — only if you want it

Kas ir CHECKSUMS.txt? Vienkārši sakot, tajā ir abu EXE failu “digitālie pirkstu nospiedumi” — SHA-256 vērtības. Ja fails pēc publicēšanas būtu mainīts, tā SHA-256 vairs nesakristu.

What is CHECKSUMS.txt? In simple terms, it contains “digital fingerprints” for both EXE files — SHA-256 values. If a file were changed after publication, its SHA-256 would no longer match.

Ikdienas lietotājam tas nav obligāts solis. Tas ir papildu veids, kā tehniski pārbaudīt konkrēto lejupielādēto failu.

This is not a required step for everyday users. It is an optional technical way to verify the exact file you downloaded.
