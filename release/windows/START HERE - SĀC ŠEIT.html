Windows SmartScreen

Jā, Windows var parādīt sarkanu vai zilu brīdinājumu.

Yes, Windows may show a red or blue warning.

Šis v{{VERSION}} preview nav Authenticode digitāli parakstīts. Tāpēc Windows nevar pārbaudīt uzticamu izdevēja identitāti un var uzrādīt “Windows aizsargāja jūsu datoru” / “Unknown publisher”.

This v{{VERSION}} preview is not Authenticode-signed. Windows therefore cannot verify a trusted publisher identity and may show “Windows protected your PC” / “Unknown publisher”.

01

Tas nav tas pats, kas vīrusa atrašana

It is not the same as detecting a virus

SmartScreen reputācijas brīdinājums pats par sevi nenozīmē, ka Windows ir atradis ļaunprogrammatūru. Tas šeit signalizē par jaunu, neparakstītu izpildāmo failu.

A SmartScreen reputation warning does not by itself mean malware was detected. Here it signals a new unsigned executable with no trusted publisher identity.

02

Kāpēc tas atkārtojas?

Why can it happen again?

Katra jauna unsigned builda fails Windows reputācijas sistēmai ir jauns objekts. Bez viena uzticama izdevēja paraksta reputāciju starp versijām ir grūtāk pārnest.

Each new unsigned build is a new file to Windows reputation systems. Without one trusted publisher signature, reputation does not carry cleanly between versions.

03

Vai tas mainīsies?

Will this change?

Iespējams. Code signing tiks pārskatīts, ja būs piemērots bezmaksas/izmaksu ziņā pamatots risinājums vai projekta apjoms to attaisnos. Konkrēts datums netiek solīts.

Possibly. Code signing will be revisited if a suitable free/cost-effective option appears or project adoption justifies it. No date is promised.

Galvenais princips: turpini tikai tad, ja PrintGuardian ZIP lejupielādēji no oficiālās QvarcY/PrintGuardian GitHub Releases lapas. Nekad neatslēdz Windows drošību globāli tikai šīs programmas dēļ.
The key rule: continue only if you downloaded the PrintGuardian ZIP from the official QvarcY/PrintGuardian GitHub Releases page. Never disable Windows security globally just for this app.

3MF tiek analizēts lokāli

3MF is analyzed locally

PrintGuardian pats neaugšupielādē tavu 3MF, profilu vai projekta saturu uz GitHub vai citu servisu.

PrintGuardian does not upload your 3MF, profiles or project contents to GitHub or another service.

Nav pilns geometry/G-code drošības audits

Not a full geometry/G-code safety audit

“Nekas aizdomīgs netika atrasts” nozīmē tikai to, ka pašreizējās pārbaudes neatrada problēmu. Tas nav drošības sertifikāts vai izdošanās garantija.

“Nothing suspicious found” only means the checks implemented today found no issue. It is not a safety certificate or success guarantee.

Update Centre announces new GitHub releases. For Portable, replace the EXE while keeping PrintGuardianData; for Installed, run the newer installer over the existing install.
